
# Clarivo — KIET Academic Hub

## Project title
A Centralized Academic Communication System with Semantic Search and Automated Alerts.

## About the project
Clarivo is a student project prototype designed to bring academic notices, deadlines, information discovery and opportunity-verification guidance into one interface.

## Features
- Student-facing home page
- Academic notices and category-based search
- Prototype academic assistant with predefined responses
- Basic opportunity warning-sign checker
- Teacher dashboard for adding and deleting demo notices
- Responsive design for desktop and mobile screens
- Profile and settings page

## Technologies used
- HTML5
- CSS3
- JavaScript

## How to run
1. Create a folder named Clarivo.
2. Save index.html, styles.css, app.js and README.md inside it.
3. Open the folder in Visual Studio Code.
4. Open index.html in a browser, or use the VS Code Live Server extension.
5. If using Live Server, right-click index.html and select "Open with Live Server".

## Current limitations
- No real AI model or semantic search backend.
- No real college login or authentication.
- No server-side PDF upload or document storage.
- No live email, push notifications or automated alerts.
- Notices created in the dashboard are temporary and are not stored on a server.
- Opportunity checks use simple text patterns and cannot establish authenticity.
- Sample notices are for demonstration only, not official KIET announcements.

## Future scope
- Backend API and database integration
- PDF text extraction and document indexing
- Semantic search and retrieval-augmented generation (RAG)
- Answers with verified document references
- Secure faculty authentication and document approval
- Automated alerts and deadline reminders
- Verified opportunity information and official-source checks

## Disclaimer
Clarivo is a student project prototype. It is not an official KIET service and is not connected to KIET's internal systems.
